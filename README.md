# agent-skills

[![skills.sh](https://skills.sh/b/PSchloss12/life-skills)](https://skills.sh/PSchloss12/life-skills)

Reusable skills and plugins for AI coding agents.

Install any skill with the [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add PSchloss12/life-skills
```

## Structure

| Directory | Contents |
|-----------|----------|
| `skills/` | Published, installable skills |
| `plugins/` | Agent plugin manifests (Claude Code marketplace format) |
| `wip/`     | Work-in-progress, not yet published |

| Skill | Description |
|-------|-------------|
| [skill-creator](skills/skill-creator/) | Guide for creating agent skills |
